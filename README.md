# Teresha Young Website 2026

2026 website revamp and prototype for Teresha Young.

## Positioning

Teresha Young — Relationship & Emotional Well-being Expert.

The website is being repositioned from a relationship-coaching-led brand to a broader authority platform serving:

1. Organisations
2. Private clients
3. Media & speaking

Corporate and organisational work is the primary website pathway.

## Project Goals

- Establish Teresha's authority within the first 30 seconds
- Create a dedicated organisational pathway
- Present private coaching clearly and warmly
- Create an evergreen Media & Speaking platform
- Integrate awards, credentials, media appearances and trusted organisations
- Provide clear but non-pushy next steps
- Build a fully responsive website
- Prepare the approved prototype for later WordPress implementation

## Development Workflow

- Claude Code — development
- GitHub — source control and pull requests
- Cloudflare Pages — website preview and review
- WordPress — final production environment after prototype approval

## Status

Prototype / development.

This repository is not the final production WordPress website.
