# URL Migration Map

## Status

No existing production website, sitemap, or URL list for the 2016-era site was supplied with this brief or found in this repository. This document records the **new** 2026 prototype's URL structure and flags the migration mapping itself as an open item.

**REVIEW REQUIRED:** if a legacy website is still live or archived, its URL list (and any inbound-link/SEO equity worth preserving) should be supplied so a real old→new redirect map can be produced before the WordPress production launch. Until then, this document only defines the new structure.

## New (2026 prototype) URL structure

| Path | Purpose |
|---|---|
| `/index.html` | Homepage |
| `/about.html` | About Teresha |
| `/organisations.html` | For Organisations (priority pathway 1) |
| `/private-coaching.html` | Private Coaching (priority pathway 2) |
| `/media-speaking.html` | Media & Speaking (priority pathway 3) |
| `/news.html` | News / media mentions |
| `/resources.html` | Free resources |
| `/contact.html` | Contact / start a conversation |
| `/privacy.html` | Privacy policy |
| `/terms.html` | Terms |
| `/404.html` | Not-found page |

No standalone `/testimonials.html` exists by design — testimonial content is categorised and placed contextually within the pages above.

## WordPress migration note

This is a static prototype for Cloudflare Pages review. When the approved prototype moves to WordPress, this same path structure should be preserved where possible (e.g. as top-level WordPress pages/slugs) so any links shared during the prototype review phase continue to resolve, and so this map can be extended with real 301 redirects if a legacy site is later identified.
